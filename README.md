# StoreLite - E-Commerce CRUD Application

A modern, fully responsive e-commerce application built with React, Vite, and Tailwind CSS v3. Featuring complete CRUD functionality for product management with a clean, professional design.

## Features

- **Product Listing**: Display all products from Fake Store API with categories and search
- **Product Details**: View detailed information about each product
- **Create Products**: Add new products with form validation
- **Update Products**: Edit existing product information
- **Delete Products**: Remove products with confirmation dialog
- **Category Filtering**: Filter products by category
- **Search Functionality**: Search products by title and description
- **Responsive Design**: Fully responsive on mobile, tablet, and desktop
- **Loading & Error States**: Professional loading spinners and error messages
- **Form Validation**: Client-side validation with inline error messages

## Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite 7
- **Styling**: Tailwind CSS v3
- **Routing**: React Router v7
- **Icons**: Lucide React
- **State Management**: React Context API
- **API**: Fake Store API

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## Installation

1. Clone the repository or extract the project files
2. Install dependencies:
\`\`\`bash
npm install
\`\`\`

3. Start the development server:
\`\`\`bash
npm run dev
\`\`\`

The application will open in your browser at `http://localhost:5173`


## Usage

### Viewing Products
- Browse all products on the home page
- Use category filter on the left sidebar
- Search for products using the search bar

### Adding a Product
- Click "New Product" button
- Fill in all required fields
- Submit to add to your store

### Editing a Product
- Click "View Details" on any product
- Click "Edit Product" button
- Modify the information
- Click "Save Changes"

### Deleting a Product
- Go to product details page
- Click the delete button (trash icon)
- Confirm deletion in the modal

## Performance Optimizations

- Lazy loading of components
- Efficient re-renders with React Context
- CSS optimization with Tailwind CSS
- Responsive images with proper aspect ratios
